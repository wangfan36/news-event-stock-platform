# Roadmap

## v1.0 当前版本

- 本地前台、REST API 与 SQLite 历史回放
- 自定义 RSS/Atom、去重、聚类和热点排序
- 事件模板、产业链映射、A/H 公司候选与解释型建议
- 可选模型、AKShare、Parquet 数据增强
- Windows 安装脚本、测试和 GitHub CI

## v1.x

- 扩充事件与产业链知识库，增加人工校验工具
- 引入公告、政策和交易所一手来源适配器
- 增加抓取失败明细、源健康度和可观测性
- 将启发式目标空间替换为可审计估值模块
- 建立历史建议命中率、超额收益和失效条件回放

## v2

- 后台任务队列与定时采集
- PostgreSQL、多用户与权限隔离
- 组合层研究、仓位预算和完整风险引擎
- 严格 PIT/OOS 回测、绩效归因与研究晋级门槛
